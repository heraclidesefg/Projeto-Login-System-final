# 🔐 Login System

> Sistema de autenticação desenvolvido com **Node.js**, **Express**, **HTML**, **CSS** e **JavaScript**.

Este projeto foi desenvolvido com fins **educacionais**, permitindo que estudantes iniciantes aprendam passo a passo como construir um sistema completo de autenticação Web utilizando tecnologias amplamente empregadas no mercado.

---

# 📚 Objetivos do Projeto

O **Login System** tem como objetivo ensinar, na prática, os principais conceitos do desenvolvimento Full Stack, incluindo:

- Estruturação de projetos profissionais
- Desenvolvimento Frontend
- Desenvolvimento Backend
- Criação de APIs REST
- Autenticação de usuários
- Criptografia de senhas
- Segurança em aplicações Web
- Boas práticas de programação

# 📦 Instalação

## 1. Clone o repositório

```bash
git clone git@github.com:heraclidesefg/Projeto-Login-System-final.git
```

Entre na pasta:

```bash
cd Login_System
```

---

## 2. Instale as dependências

```bash
npm install
```

---

## 3. Executar o projeto

Modo normal

```bash
npm start
```

Modo desenvolvimento

```bash
npm run dev
```
